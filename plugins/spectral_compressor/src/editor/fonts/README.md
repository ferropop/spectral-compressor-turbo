Turbo Credit is a modified Noto Sans Regular font. Original font by Google, licensed under the SIL Open Font License 1.1 (LICENSE). Fullwidth ASCII glyphs are centered in one-em cells; the modified family is renamed Turbo Credit. Reproduce with scripts/make_credit_font.py and the pinned NIH-plug assets NotoSans-Regular.ttf. FontTools is a build-time helper; the font is embedded, with no user dependency.
